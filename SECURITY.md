# Security Policy

PortPrimer is an educational TCP connect scanner for systems you own or have clear permission to test.

## Responsible Use

- Use PortPrimer only on authorized targets.
- Keep lab targets, such as Metasploitable 2, isolated from public networks.
- Do not use PortPrimer for random public scanning.
- An open port is not automatically a vulnerability.

## Reporting Security Issues

If you find a security issue in PortPrimer itself, open a private report through your hosting platform's security reporting feature if available. Include the affected version, a clear description, and reproduction steps.

## Scope

PortPrimer intentionally avoids stealth scanning, exploitation, credential testing, brute forcing, OS fingerprinting, CIDR scanning, and aggressive banner grabbing.
